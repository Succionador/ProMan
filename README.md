## 🎯 简介

「范工管理」是一款面向**建设工程项目管理**领域的在线答题练习系统，涵盖一级/二级建造师考试核心内容，共十个章节、125道精选习题，支持手机和电脑随时练习。

| 章节 | 内容 |
|:---:|------|
| 第 1 章 | 建设工程项目组织、规划与控制 |
| 第 2 章 | 建设工程项目管理相关体系标准 |
| 第 3 章 | 建设工程招标投标与合同管理 |

| 第 7 章 | 建设工程施工安全管理 |
| 第 8 章 | 绿色建造及施工现场环境管理 |
| 第 9 章 | 国际工程承包管理 |
| 第 10 章 | 建设工程项目管理智能化 |

## ✨ 功能特点

- 💾 **进度自动保存** — 退出后可继续做题，不丢失进度
- ❌ **错题巩固** — 随时查看和复习错题
- 📊 **知识点分析** — 了解各章节掌握情况
- 📱 **响应式设计** — 同时支持手机和电脑访问
- 🔐 **密码保护** — 需输入正确密码方可进入练习

---

## 🛠️ 技术栈

- 纯前端实现，无需后端服务器
- HTML5 + CSS3 + JavaScript
- 部署于 GitHub Pages，全球高速访问

## 🚀 快速开始

### 在线访问

直接访问 GitHub Pages 地址即可使用：
> https://succionador.github.io/ProMan/

### 本地使用

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/Succionador/ProMan.git
   ```
2. 用浏览器直接打开 `index.html` 或任意章节文件
3. 输入章节密码即可开始练习
